## 五、資料格式

### 5.1 Config 層級

- `pulses`：Pulse 來源列表，每個為單一訊號（無 _Hi/_Lo/_Force 後綴）。如 `["iPulse_1us", "iPulse_1ms"]` 對應模組輸入，Verilog 中單行宣告：`input iPulse_1us, iPulse_1ms,`

### 5.2 JSON 節點格式

```json
{
  "name": "node_name",
  "seq_type": "Output | Input",
  "depends_on_hi": ["dep1", "__HIGH__"],
  "depends_on_lo": ["dep2"],
  "depends_on_hi_inv": {"dep1": false},
  "depends_on_lo_inv": {},
  "depends_on_hi_use": {"dep1": "self"},
  "depends_on_lo_use": {},
  "depends_on_hi_groups": [["dep1", "__HIGH__"]],
  "depends_on_lo_groups": [["dep2"]],
  "pulse_hi": "iPulse_1us",
  "pulse_lo": "iPulse_1us",
  "pulse_force": "iPulse_1us",
  "deb_enable": false,
  "deb_init": 0,
  "deb_cycle_hi": 2,
  "deb_cycle_lo": 2,
  "deb_cycle_sync": 2,
  "deb_pulse": "iPulse_1us",
  "cycle_hi": 8,
  "cycle_lo": 4,
  "cycle_force": 2,
  "recover": 3,
  "init": 0,
  "force_val": 0,
  "cycle_sync": 0,
  "od": 0
}
```

- `seq_type`：`"Output"` 或 `"Input"`
- `depends_on_hi` / `depends_on_lo`：iHi / iLo 依賴，可含 `"__HIGH__"`、`"__LOW__"`
- `depends_on_hi_inv` / `depends_on_lo_inv`：依賴項是否反相
- `depends_on_hi_use` / `depends_on_lo_use`：`"self"`=節點本身、`"hi"`=該節點 iHi、`"lo"`=該節點 iLo（僅 output 可選 hi/lo）
- `depends_on_hi_groups` / `depends_on_lo_groups`：依賴分組（F-DEP-08），組內 AND、組間 OR
- `depends_on_hi_inv_groups` / `depends_on_lo_inv_groups`：per-group per-item 反相設定（list of list of bool）
- `depends_on_hi_use_groups` / `depends_on_lo_use_groups`：per-group per-item use mode 設定（list of list of str）
- `pulse_hi` / `pulse_lo` / `pulse_force`：該節點使用的 pulse（對應 config `pulses`）
- `deb_enable` / `deb_init` / `deb_cycle_hi` / `deb_cycle_lo` / `deb_cycle_sync` / `deb_pulse`：input 專用，DEB 模組參數
- `init`：PSEQCELL 初始值（0 或 1），僅 output 節點使用；GUI 以「INIT」下拉選單置於 CYCLE_LO 右側

### 5.3 Verilog 檔名與模組命名（F-VER-04）

- **依檔名產生**：產生 Verilog 時依儲存檔名自動產生 module name 與 include guard
- **module name**：檔名（不含 .v），將 `.`、`-`、空格替換為 `_`（如 `my_pwrseq.v` → `my_pwrseq`）
- **include guard**：上述名稱大寫 + `_V` 後綴（如 `my_pwrseq.v` → `MY_PWRSEQ_V`）
- 若未指定檔名（如 CLI 直接輸出），則使用 config 的 `module_name`

### 5.4 Verilog 埠命名與順序

- **Port 順序**：iRst → iClk_Core → pulses（單行）→ 節點（依 config.rails 順序）→ iForce
- **埠命名**：output 用 oXXX，input 用 iXXX

| 類型 | 輸出 | 輸入 |
|------|------|------|
| output | oXXX | - |
| input | - | iXXX |

### 5.5 Verilog 內部訊號命名

- **全小寫**，`_hi`、`_lo` 放在變數後面
- 輸出：`{name_lower}`（如 sig_2）
- Hi/Lo 條件：`{name_lower}_hi`、`{name_lower}_lo`（如 sig_2_hi、sig_2_lo）
- Debounce：`{name_lower}_deb`（如 sig_1_deb）

## 六、設計說明（供功能增減參考）

| 項目 | 說明 |
|------|------|
| 循環依賴 | Hi 與 Lo 分開檢查。iHi 決定上電順序，iLo 決定關電順序。例如 A iHi 依賴 B、B iLo 依賴 A 不成立環（狀態不同）。|
| 儲存行為 | 儲存 JSON 不驗證，允許有問題時仍可存檔。產生 Verilog 時才驗證。|
| 節點順序 | 左側列表順序可拖拉調整，影響編輯區顯示與 Verilog port 順序、拓撲排序。|
| 套用行為 | 套用時僅更新該節點，其他節點保留 config 既有資料，避免依賴遺失。|
| Input Debounce | input 啟用 deb_enable 時，使用 DEB 模組產生 xxx_deb 訊號，其他節點依賴時使用 debounced 訊號。|
| 相關檔案 | config_models.py、validator.py、verilog_generator.py、gui.py、drawio_export.py |
| Draw.io 版面 | 輸入欄(INPUT_COL_X) → 閘欄(GATE_COL_X，OR/AND 同欄) → Cell(CELL_START_X) → 輸出名稱；輸入 y 與閘中心一致不強制 40pt；O 線水平無 waypoints；waypoint 支援 per-point 不對齊以保直線。 |
