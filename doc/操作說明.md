# Power Sequence Generator 操作說明

## 一、安裝與啟動

### 1.1 環境需求

- Python 3.8 以上
- 已安裝 pip

### 1.2 安裝相依套件

```bash
cd pwrseq_gen
pip install -r requirements.txt
```

### 1.3 啟動程式

```bash
python main.py
```

或

```bash
python gui.py
```

## 二、介面說明

### 2.1 視窗配置

- **頂部工具列**：六個按鈕（新增、刪除、載入、儲存、產生 Verilog、匯出 Draw.io）+ 右側釘選按鈕
- **左側面板**：Sequence Node 列表 + Timing Signals 管理
- **右側面板**：Accordion 折疊式編輯區，每個 Node 可點擊標題列展開/收合
- **底部**：驗證訊息（綠色表示通過，紅色表示有錯誤）

### 2.2 工具列按鈕


| 按鈕             | 功能                                       |
| -------------- | ---------------------------------------- |
| + Add          | 新增一個 Sequence Node，預設名稱為 SIG_1、SIG_2... |
| - Delete       | 刪除左側列表中目前選取的 Node                       |
| Open JSON      | 從檔案載入先前儲存的設定                             |
| Save JSON      | 將目前設定儲存為 JSON 檔                          |
| Generate Verilog | 驗證通過後，產生 Verilog 模組檔（Ctrl+G）         |
| Generate C     | 驗證通過後，產生韌體 C（power.c 風格，Ctrl+Shift+G） |
| Export Draw.io | 匯出 Draw.io XML 依賴關係圖（Ctrl+E）             |
| 📌             | 釘選視窗至螢幕最上層（再按取消）                        |

## 三、操作步驟

### 3.1 新增 Power Rail

1. 點擊「+ 新增 Rail」
2. 左側列表會出現新 rail（預設名稱如 VDD_1）
3. 在右側對應的編輯區塊中填寫參數

### 3.2 編輯參數（參考 x15_pseq）


| 欄位                      | 說明                                                      |
| ----------------------- | ------------------------------------------------------- |
| **名稱**                  | 節點識別名稱，需唯一                                              |
| **類型**                  | **Output (輸出)**：僅輸出；**Input (輸入)**：僅輸入，供其他節點依賴          |
| **CYCLE_HI / CYCLE_LO** | PSEQCELL 時序參數（僅 output 節點）                              |
| **INIT**                | PSEQCELL 初始值（0 或 1），下拉選單，位於 CYCLE_LO 右側；僅 output 節點顯示 |
| **依賴於**                 | 勾選此節點需等待的節點（Hi 依賴 / Lo 依賴分開設定）                          |


### 3.3 設定依賴關係

- 在「依賴於」區塊中，勾選此節點所依賴的其他節點
- **無勾選**：表示第一階，無依賴其他 power rail，PSEQCELL 的 iHi 會直接接 `1'b1`，條件恆滿足，可依 CYCLE_HI 時序啟動
- **勾選一個或多個**：需等所有勾選的 rail 輸出為 High 後，此 rail 才會啟動
- **關機順序**：自動依賴關係反轉（依賴此 rail 的 rail 關閉後，此 rail 才能關閉）

> **無依賴 rail 的 Verilog 行為**：當「依賴於」為空時，產生的 Verilog 會設定 `wire wHi_XXX = 1'b1`，使 PSEQCELL 的 iHi 直接輸入 1'b1，表示此 rail 一給電即可依序啟動，無需等待其他 rail。

### 3.4 刪除 Rail

1. 在左側列表中點選要刪除的 rail
2. 點擊「- 刪除選取」

### 3.5 儲存設定

1. 確認底部驗證訊息為「✓ 驗證通過」
2. 點擊「儲存 JSON」
3. 選擇儲存路徑與檔名（副檔名 .json）

### 3.6 載入設定

1. 點擊「載入 JSON」
2. 選擇先前儲存的 JSON 檔
3. 程式會載入並覆蓋目前設定

### 3.7 產生 Verilog

1. 確認驗證通過
2. 點擊「Generate Verilog」（或 Ctrl+G）
3. 選擇儲存路徑與檔名（副檔名 .v）
4. 產生的檔案需與 `PSEQCELL.v` 一起編譯

### 3.8 產生 C（韌體）

1. 確認驗證通過
2. 點擊「Generate C」（或 Ctrl+Shift+G）
3. 選擇儲存路徑與檔名（建議 `power.c`；檔名決定 `#ifndef POWER_C` 與 `power_Init` 等函式前綴）
4. 輸出內容含 `pwrcell_t` 結構、`power_var` 初始化、`oemgpio_DI_Get` 條件式、`pwrcell_handle` 與 timer ISR 樣板；需搭配專案內 `pwrcell` 函式庫與 `_user.h`

### 3.9 匯出 Draw.io 依賴關係圖

1. 點擊「Export Draw.io」
2. 選擇儲存路徑與檔名（副檔名 .xml）
3. 以 [diagrams.net](https://app.diagrams.net) 開啟檢視
4. 圖中顯示：Input 節點、Output 節點（含 H_Deb / L_Deb）、依賴連線（Hi 綠色實線、Lo 紅色虛線）、AND/OR 閘

### 3.10 匯出 WaveDrom 時序圖

1. 確認驗證通過
2. 點擊「Export WaveDrom」（或 Ctrl+Shift+E）
3. 在對話框中為每個 **Input** 設定模擬用 Hi/Lo：常高、常低、WaveDrom pattern（例如 `0.1.`），或 **訊號條件**（可選其他 Input / Output，group 內 AND、groups 間 OR，與節點 Cond 相同）；此設定**僅供時序模擬**，不會寫入 rail 的 `depends_on_*`
4. 可調整模擬步數與 **hscale**（WaveDrom 每 step 水平寬度，預設 **1**；設 **2** 則圖上每格約兩倍寬）。JSON 欄位：`hscale`（舊版 `cond_step_delay` 載入時會對應成 `hscale`）。邏輯模擬的條件延遲固定為 1 step。
5. **Load** / **Save** / **Save As…**：讀寫 `*_wavedrom_scenario.json`（**Save** 寫入 sidecar 或上次路徑；**Save As…** 另選路徑）。開啟專案時若無內嵌 `wavedrom_scenario`，會自動讀同目錄 sidecar
6. **Export WaveDrom…**：產生 WaveJSON（訊號列順序同專案 `rails` 宣告；`i*`/`o*` 前綴；**條件箭頭**）；貼至 [WaveDrom Editor](https://wavedrom.com/editor.html)
7. Preview 可選「WaveDrom」。波形為 0/1 與 `.` 延伸（例如全程高為 `1`…`1` 書夾式，勿用 `1200`——WaveDrom 會把 `2` 當 bus 符號）
8. **限制**：邏輯級模擬（不計 `cycle_hi`/`cycle_lo`、pulse、DEB）；不含 clock/bus/edge。同一 step 內依 Hi 路徑拓撲順序處理 output，並在該 output 變化後刷新依賴它的 input（如 PG←EN），避免 PG 已高但下游 output 晚兩格才轉態

## 四、驗證規則

程式會自動檢查以下項目：


| 檢查項目 | 說明                  |
| ---- | ------------------- |
| 名稱重複 | 各 rail 名稱不可相同       |
| 依賴存在 | 「依賴於」中勾選的 rail 必須存在 |
| 循環依賴 | 不可出現 A→B→C→A 的循環    |
| 空名稱  | 名稱不可為空白             |


若有錯誤，底部會顯示紅色錯誤訊息，且無法儲存或產生 Verilog。

## 五、範例流程

### 5.1 三階 Power Sequence（VDD_CORE → VDD_IO → VDD_GPU）

1. 新增三個 rail
2. 第一個命名為 VDD_CORE，依賴於不勾選，CYCLE_HI=8、CYCLE_LO=4
3. 第二個命名為 VDD_IO，依賴於勾選 VDD_CORE，CYCLE_HI=4、CYCLE_LO=2
4. 第三個命名為 VDD_GPU，依賴於勾選 VDD_CORE 與 VDD_IO，CYCLE_HI=4、CYCLE_LO=2
5. 儲存 JSON 或產生 Verilog

### 5.2 使用範例設定

1. 點擊「載入 JSON」
2. 選擇專案中的 `sample_config.json`
3. 可依需求修改後再儲存或產生 Verilog

## 六、參數說明（進階）


| 參數          | 預設值 | 說明                                                        |
| ----------- | --- | --------------------------------------------------------- |
| CYCLE_HI    | 8   | 條件滿足後，需連續 CYCLE_HI 個 pulse 輸出才變 High                      |
| CYCLE_LO    | 4   | 條件滿足後，需連續 CYCLE_LO 個 pulse 輸出才變 Low                       |
| cycle_force | 2   | Force 訊號 debounce 週期（JSON 可設定，GUI 未顯示）                    |
| recover     | 3   | PSEQCELL RECOVER 參數（JSON 可設定）                             |
| init        | 0   | PSEQCELL 初始值：0=Low, 1=High；output 節點可在編輯區以「INIT」下拉選單（0/1）設定 |
| force_val   | 0   | Force 時輸出狀態：0=Low, 1=High                                 |


---

## 七、注意事項

1. **PSEQCELL.v**：產生的 Verilog 模組會對 output 節點實例化 PSEQCELL，請確保 `PSEQCELL.v` 在編譯路徑中
2. **iForce**：產生的 top 模組有 `iForce` 輸入，若不用可接 `1'b0`
3. **iPulse_Hi / iPulse_Lo / iPulse_Force**：由外部 IO 輸入，不在模組內產生。需由 top 層或外部邏輯提供 sample pulse
4. **JSON 格式**：儲存的 JSON 可手動編輯，但需符合格式，載入時會忽略未知欄位

## 八、疑難排解


| 問題           | 可能原因                 | 解決方式                    |
| ------------ | -------------------- | ----------------------- |
| 無法儲存         | 驗證未通過                | 查看底部錯誤訊息，修正後再試          |
| 無法產生 Verilog | 同上                   | 同上                      |
| 載入 JSON 失敗   | 檔案格式錯誤               | 檢查 JSON 語法，確保 rails 為陣列 |
| 循環依賴         | A 依賴 B，B 依賴 A（直接或間接） | 調整依賴關係，確保為 DAG          |
