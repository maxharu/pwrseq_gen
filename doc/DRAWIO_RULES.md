# Draw.io 圖表生成規則

本文件定義 Power Sequence 結構圖（Draw.io XML）的版面、樣式與連接規則。產圖程式（`drawio_export.py`）應依此規則輸出，以減少人工二次調整。

---

## 整體流程與版面

- **流向**：由左到右。
- **欄位順序**：**輸入欄** → **NOT 欄**（若有反相 use mode）→ **AND 欄** → **OR 欄**（間隔 80pt）→ **Cell 欄**（H_Deb/L_Deb）→ **輸出名稱欄**。
- **範例流程**：`IN1 --->|AND|--->|OR|--->|Cell|--->(小圓圈)---> 輸出訊號`。
- **Cell 順序**：依 config 節點順序由上而下排列；啟用 Optimize Layout 時依拓撲排序 + 重心法排列。

---

## 一、輸入訊號 (Input Signals)


| 項目         | 規則                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| **位置**     | 圖形最左側，所有輸入文字框同一垂直線（`INPUT_COL_X`）。                                                                        |
| **命名**     | 如 `SIG_1`、`~SIG_4`、`~SIG_3`；名稱前加 `~` 表示反向訊號。                                                              |
| **對齊（必守）** | 每一條輸入訊號線必須在**垂直方向**與其「第一個連接到的邏輯閘輸入端」對齊。例如：`SIG_1` 對齊最上方 AND 的上方輸入端；`~SIG_4` 對齊該 AND 的下方輸入端及中間 AND 的上方輸入端。 |
| **延伸**     | 輸入線自圖形左邊界開始，水平延伸至與閘的連接點。輸入→閘的走線可經由通道 waypoint 轉向，連接端不對齊 40pt 以保持與輸入標籤同高的直線。                               |


---

## 二、邏輯閘 (AND / OR)


| 項目               | 規則                                                                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **分層與左右順序**      | 依處理順序分層，**愈前一級放在愈左邊**。直接接輸入的 AND 為第一層，接閘輸出的 OR 為第二層。若某個 cell 的邏輯同時包含 AND 與 OR 且視覺上會重疊，則必須分層：**AND 在左、OR 在右**。                                                                         |
| **層級間距**         | 相鄰邏輯層級之間水平間隔固定為 **80pt**（GAP）。例如 AND 欄與 OR 欄之間 80pt，OR 欄與 Cell 之間 80pt。                                                                                                               |
| **閘型**           | AND 為 D 形、兩輸入一輸出；OR 為弧形、兩輸入一輸出；NOT 為三角形反相器（`inverter_2`，40×20pt）。皆使用 mxgraph.electrical.logic_gates。 |
| **NOT 閘**        | 當 use mode 為 hi/lo 且反相時，在邏輯閘輸出與目標閘之間插入 NOT 閘。NOT 閘放在目標 AND/OR 閘輸入端左側（間距 80pt），y 對齊目標閘的輸入 pin，不與其他元件重疊。 |
| **AND 欄 / OR 欄** | AND 閘位於 `and_col_x`，OR 閘位於 `or_col_x`（`or_col_x = and_col_x + 80 + AND_GATE_W`）。多個 AND 垂直間距 80pt（AND_GATE_DY）。同一列 Hi/Lo 若有兩個 OR，垂直錯開 40pt（OR_GATE_OFFSET_HI_Y / OR_GATE_OFFSET_LO_Y）。 |


---

## 三、去抖動模組 (H_Deb / L_Deb)


| 項目        | 規則                                                                                     |
| --------- | -------------------------------------------------------------------------------------- |
| **佈局**    | 每個輸出路徑有一對垂直堆疊的矩形：上方 **H_Deb**、下方 **L_Deb**。                                            |
| **輸入線樣式** | 連到 **H_Deb** 的線：**實心綠線**（`#059669`）。連到 **L_Deb** 的線：**虛線紅線**（`#dc2626`），表示 Lo 依賴／關電路徑。 |
| **輸出**    | H_Deb 與 L_Deb 的輸出在 inner 匯合為單一線路，再經小圓圈接到該路徑的輸出訊號。                                      |


---

## 四、輸出訊號 (Output Signals)


| 項目     | 規則                                                                                                                    |
| ------ | --------------------------------------------------------------------------------------------------------------------- |
| **位置** | 圖形最右側，輸出名稱文字框在 Cell 右方（`output_name_offset_x`）。                                                                       |
| **命名** | 如 `SIG_2`、`SIG_3`、`SIG_5`。                                                                                            |
| **連接** | 從 H_Deb/L_Deb 匯合點（inner 輸出）到輸出訊號線之間，應有一個**小圓圈符號**（橢圓、固定長寬比、直徑 8pt），輸出線再水平延伸至圖形右邊界。即：**inner → 小圓圈 → 輸出名稱**，兩段線皆正交、水平。 |
| **對齊** | 輸出名稱 y 與 cell 垂直置中對齊，使 O 線水平、無轉角。                                                                                     |


---

## 五、連接線 (Connectors / Wires)


| 項目            | 規則                                                                                              |
| ------------- | ----------------------------------------------------------------------------------------------- |
| **預設**        | 實心黑線（`#000000`），末端帶箭頭（endArrow=classic; endFill=1），表示訊號方向。                                      |
| **Hi 路徑**     | 連到 H_Deb 的邊：實心綠線（`STROKE_HI`）。                                                                  |
| **Lo 路徑**     | 連到 L_Deb 的邊：虛線紅線（`STROKE_LO`）。                                                                  |
| **佈線原則**      | 以**垂直與水平線段**為主（orthogonalEdgeStyle），避免斜線。盡量減少線條交叉；若需交叉，保持路徑可辨。分岔點（一輸入接多個閘）要清楚標示。整體版面整齊、層級與對齊一致。不要直接穿越元件，要繞開元件(包含cell)。走線不要重疊。 |
| **Waypoints** | 走線可經通道 waypoint 轉向；與輸入標籤同高之端點可不對齊 40pt，以保持直線。AND→OR 跨層時在 `or_col_x` 轉折。                         |


---

## 六、檢查清單與常數參考

- 左→右：輸入 → AND 欄 → OR 欄（80pt）→ Cell（H_Deb/L_Deb）→ 小圓圈 → 輸出。
- 輸入：每條輸入線垂直對齊其第一個連接的閘輸入端。
- 閘：AND 在左、OR 在右，層級間 80pt，不重疊。
- 線條：Hi 綠、Lo 紅、預設黑；正交、少交叉、箭頭與分岔清楚。走線間不要有重疊的線段。
- 輸出：匯合點與輸出名稱之間有小圓圈。

### 常數摘要（實作參考）


| 常數                                     | 值                           | 說明        |
| -------------------------------------- | --------------------------- | --------- |
| GAP                                    | 80                          | 基礎間距（pt）。 |
| GRID                                   | 40                          | 座標對齊格距。   |
| INPUT_COL_X                            | 160                         | 輸入欄 x。    |
| INPUT_LABEL_W / H                      | 80 / 20                     | 輸入標籤寬高。   |
| AND_GATE_W / H                         | 80 / 40                     | AND 閘寬高。  |
| OR_GATE_W / H                          | 80 / 40                     | OR 閘寬高。   |
| NOT_GATE_W / H                         | 40 / 20                     | NOT 閘寬高。  |
| OUTPUT_CIRCLE_SIZE                     | 8                           | 小圓圈直徑。    |
| STROKE_HI / STROKE_LO / STROKE_DEFAULT | #059669 / #dc2626 / #000000 | 線條顏色。     |

## 相關檔案

- **實作**：`drawio_export.py`（`generate_drawio()`）。模組 docstring 與註解依本規則一～六標註，常數與版面計算與上表一致。
- **Layout engine**：`layout_engine.py`（`layout_drawio()`）。匯出後可選用，對 XML 做自動版面調整：頂點與 waypoints 對齊格點（預設 40pt）、可選重疊頂點錯開；與本規則之格距一致，可擴充更多檢查或微調。
- **需求對應**：`需求表.md` 第二節 F-DIO-01～F-DIO-08。
- **範本圖**：可搭配 `assets/` 下之範本圖與說明使用，作為視覺對照。
