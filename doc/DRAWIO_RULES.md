# Draw.io 圖表生成規則

本文件定義 Power Sequence 結構圖（Draw.io XML）的版面、樣式與連接規則。產圖程式（`drawio_export.py`）應依此規則輸出，以減少人工二次調整。

---

## 整體流程與版面

- **流向**：由左到右。
- **欄位順序**：**輸入欄** → **NOT 欄**（若有任何反相）→ **AND 欄** → **OR 欄**（間隔 80pt）→ **Cell 欄**（H_Deb/L_Deb）→ **輸出名稱欄**。
- **範例流程**：`IN1 --->|AND|--->|OR|--->|Cell|--->(小圓圈)---> 輸出訊號`。反相時：`IN1 --->|NOT|---> ... 或 Cell.O --->|NOT|--->|AND|---> ...`。
- **Cell 順序**：固定依拓撲排序 + 重心法排列（被依賴者在前、依賴緊密者相鄰）。

---

## 一、輸入訊號 (Input Signals)


| 項目         | 規則                                                                                                        |
| ---------- | --------------------------------------------------------------------------------------------------------- |
| **位置**     | 圖形最左側，所有輸入文字框同一垂直線（`INPUT_COL_X`）。                                                                        |
| **命名**     | 一律使用正向名稱（如 `SIG_1`），不再使用 `~SIG_1` 文字表達反相。反相由 NOT 閘呈現（見二、NOT 閘）。                                              |
| **對齊（必守）** | 每一條輸入訊號線必須在**垂直方向**與其「第一個連接到的邏輯閘輸入端」對齊。                                                                  |
| **延伸**     | 輸入線自圖形左邊界開始，水平延伸至 NOT 閘（若反相）或閘的連接點。輸入→閘的走線可經由通道 waypoint 轉向，連接端不對齊 40pt 以保持與輸入標籤同高的直線。                       |


---

## 二、邏輯閘 (AND / OR)


| 項目               | 規則                                                                                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **分層與左右順序**      | 依處理順序分層，**愈前一級放在愈左邊**。直接接輸入的 AND 為第一層，接閘輸出的 OR 為第二層。若某個 cell 的邏輯同時包含 AND 與 OR 且視覺上會重疊，則必須分層：**AND 在左、OR 在右**。                                                                         |
| **層級間距**         | 相鄰邏輯層級之間水平間隔固定為 **80pt**（GAP）。例如 AND 欄與 OR 欄之間 80pt，OR 欄與 Cell 之間 80pt。                                                                                                               |
| **閘型**           | AND 為 D 形、兩輸入一輸出；OR 為弧形、兩輸入一輸出；NOT 為三角形反相器（`inverter_2`，40×20pt）。皆使用 mxgraph.electrical.logic_gates。 |
| **NOT 閘（共用）**    | 任何 `inv=True` 的依賴都用 NOT 閘呈現（不再用 `~Name` 文字標籤）。同一個「來源 d + use_mode」即使在多個位置被反相，**共用一顆 NOT 閘**，從 NOT 輸出 fan-out 到所有目標。**兩個 NOT 欄**：(a) **Input NOT 欄**（`input_not_col_x = input_right + 80`）放 input 反相的 NOT，y 對齊 input label 下方（NOT 上邊貼 label 下邊），讓非反相 input 的水平走線從 NOT 上方通過、不穿越 NOT vertex；(b) **Logic NOT 欄**（`logic_not_col_x = and_col_x − 80 − NOT_GATE_W`）放 output 反相的 NOT，y 對齊邏輯來源中心。皆用 `_find_non_overlapping_y` 避免與其他元件重疊。NOT 的輸入來源：input → input label；output + use=self → cell inner；output + use=hi/lo → 該 rail 的 hi/lo 邏輯輸出（AND/OR 閘）。 |
| **AND 欄 / OR 欄** | AND 閘位於 `and_col_x`，OR 閘位於 `or_col_x`（`or_col_x = and_col_x + 80 + AND_GATE_W`）。多個 AND 垂直間距 80pt（AND_GATE_DY）。同一列 Hi/Lo 若有兩個 OR，垂直錯開 40pt（OR_GATE_OFFSET_HI_Y / OR_GATE_OFFSET_LO_Y）。 |

## 三、Power Sequence Cell（PSEQCELL.xml 結構）


| 項目         | 規則                                                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------------------------------------ |
| **結構**     | 每個 output node 由 4 個獨立 `mxCell` 構成（`parent="1"`，**不再用 group 包裝**）：底層 inner 矩形（80×80）+ 上覆 H_Deb（50×20，貼 inner 左上）+ L_Deb（50×20，貼 inner 左下）+ O 矩形（20×20，內嵌 inner 右側）。 |
| **inner**  | `style=rounded=0;whiteSpace=wrap;html=1;`，位於 `(px, py)`，無 value。                                                          |
| **H_Deb**  | `rounded=1`，位於 `(px, py+10)`，value="H_Deb"。                                                                              |
| **L_Deb**  | `rounded=1`，位於 `(px, py+50)`，value="L_Deb"。                                                                              |
| **O 矩形**   | `rounded=1`，位於 `(px+60, py+30)`，value="O"，是輸出 anchor（取代過去 8pt 小圓圈）。                                                       |
| **輸入線樣式** | 連到 **H_Deb** 的線：**實心綠線**（`#059669`）。連到 **L_Deb** 的線：**虛線紅線**（`#dc2626`），表示 Lo 依賴／關電路徑。內部不再放 "H" / "L" edge 標籤。 |
| **輸出**     | 從 O 矩形右側拉一條水平邊到該路徑的輸出名稱文字框（單段、無轉角）。 |


---

## 四、輸出訊號 (Output Signals)


| 項目     | 規則                                                                                                       |
| ------ | -------------------------------------------------------------------------------------------------------- |
| **位置** | 圖形最右側，輸出名稱文字框在 Cell 右方（`output_name_offset_x = CELL_GROUP_W + gap_co`）。                                 |
| **命名** | 如 `SIG_2`、`SIG_3`、`SIG_5`。                                                                               |
| **連接** | 直接從 cell 內嵌的 O 矩形右邊拉一條水平邊到輸出名稱文字框（**單段、無轉角、無中介小圓圈**）。                                                  |
| **對齊** | 輸出名稱 y 與 O 矩形中心對齊，使邊水平。                                                                                  |


---

## 五、連接線 (Connectors / Wires)


| 項目            | 規則                                                                                              |
| ------------- | ----------------------------------------------------------------------------------------------- |
| **預設**        | 實心黑線（`#000000`），末端帶箭頭（endArrow=classic; endFill=1），表示訊號方向。                                      |
| **Hi 路徑**     | 連到 H_Deb 的邊：實心綠線（`STROKE_HI`）。                                                                  |
| **Lo 路徑**     | 連到 L_Deb 的邊：虛線紅線（`STROKE_LO`）。                                                                  |
| **佈線原則**      | 以**垂直與水平線段**為主（orthogonalEdgeStyle），避免斜線。盡量減少線條交叉；若需交叉，保持路徑可辨。分岔點（一輸入接多個閘）要清楚標示。整體版面整齊、層級與對齊一致。不要直接穿越元件，要繞開元件(包含cell)。走線不要重疊。 |
| **Waypoints** | 走線可經通道 waypoint 轉向；與輸入標籤同高之端點可不對齊 40pt，以保持直線。AND→OR 跨層時在 `or_col_x` 轉折。                         |


---

## 六、檢查清單與常數參考

- 左→右：輸入 → NOT 欄（若有反相）→ AND 欄 → OR 欄（80pt）→ Cell（PSEQCELL：inner + H_Deb / L_Deb / O）→ 輸出名稱。
- 輸入：每條輸入線垂直對齊其第一個連接的閘輸入端；反相一律用 NOT 閘。
- 閘：AND 在左、OR 在右，層級間 80pt，不重疊；NOT 共用同一來源+use_mode。
- Cell：4 個獨立 mxCell（無 group）；輸出 anchor 為 O 矩形（取代過去小圓圈）。
- 線條：Hi 綠、Lo 紅、預設黑；正交、少交叉、箭頭與分岔清楚。走線間不要有重疊的線段。
- 輸出：匯合點與輸出名稱之間有小圓圈。

| 常數                                     | 值                           | 說明        |

## 相關檔案

- **實作**：`drawio_export.py`（`generate_drawio()`）。模組 docstring 與註解依本規則一～六標註，常數與版面計算與上表一致。
- **Layout engine**：`layout_engine.py`（`layout_drawio()`）。匯出後可選用，對 XML 做自動版面調整：頂點與 waypoints 對齊格點（預設 40pt）、可選重疊頂點錯開；與本規則之格距一致，可擴充更多檢查或微調。
- **需求對應**：`需求表.md` 第二節 F-DIO-01～F-DIO-08。
